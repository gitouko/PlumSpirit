# Keyboard Shortcuts

Every shortcut PlumSpirit has, as you have set them now. To change one, open
{cmd:ShowKeybinds}: **Change…** takes the next key you press, **Add…** gives a command a
second shortcut, **Clear** removes them and **Reset** brings the default back. A shortcut
another command already uses is moved only after you confirm.

> Some keys depend on where you are: in the Track List the note tools' keys wait for the
> Piano Roll, and Tab ({key:SwitchView}) switches between the two.

{shortcuts}

basics.
