Microsoft's instructions for application-local runtime deployment:
https://learn.microsoft.com/en-us/cpp/windows/walkthrough-deploying-a-visual-cpp-application-to-an-application-local-folder
The installed Visual Studio Redist.txt points to its distributable code list:
https://aka.ms/vs/18/redistribution

Windows 10/11 supplies the Universal CRT and other Windows system DLLs. Keep
vcruntime140.dll beside PlumSpirit.exe when sharing the portable folder.
